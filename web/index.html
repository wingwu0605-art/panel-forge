分镜模板库

怎么用（30 秒）
  1. 在「分镜模板库」选一套版式（或先写剧情，让引擎替你挑）。
  2. 点格子 → 选图；或把一批图直接拖进画布，按阅读顺序自动填。
  3. 拖图可调位置，Alt+滚轮缩放；Ctrl+V 粘贴到选中格。
  4. 「分镜表」拿每格景别＋生图提示词；「导出」出 PNG/SVG。
  5. 换模板时图片会按阅读顺序跟着搬家，方便横向对比版式。
  6. 隐私：图片全程在你浏览器里处理（FileReader → SVG → canvas），不上传、不落盘；关掉标签页就清空。只有剧情文字会发给你自己配置的模型。
